Git
Your everyday git loop from now on
Because you set up tracking (-u), future pushes are just git push — no need for origin main again.

After making changes:
git add -A
Review what's staged (optional but good habit):
git status
Commit with a message describing the change:
git commit -m "Describe what you changed"
Upload:
git push
